## ★ 원칙 (미오 님 18:32)
1. *정미년은 바탕, 앞에 세우는 건 하위 주제 + 음악 연결.* 한 달 반 내내 「정미년」을 외치지 않는다. 훅·첫 장·제목은 하위 주제(그림·소품·여행·일간·빛·흙·물·소리)로, 정미년은 본문 한 줄로 잇는다.
2. 모든 편 끝은 고요 음악으로 잇는다(그 편과 맞는 천간·오행 본편 + 한 줄 이유). 아래 「연결 음악」은 *초안* — 명리 에이전트 검토 후 확정(지침 17절).
3. 인스타 고정 칸 그대로: 월 18:00 캐러셀(절기·날짜) / 화·토 18:00 릴스 / 수·금·일 18:00 캐러셀 + 18:20 릴스판 / 목 18:00 고요의 그림 읽기. 남는 해석은 영상으로 21:00(입춘만 13:00).
4. 두 창 *동시 진행·서로 기다리지 않음*(아래 분업). 이미 예약된 것(12/31 18:00 59번 등)은 건드리지 않는다.
5. 새 폴더는 `"approved": false`로 넣고, 미오 님 확인 뒤 true.
