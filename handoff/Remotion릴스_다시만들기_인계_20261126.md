## 틀과 예시
- 코드: 맥 바탕화면/플리제작도구/remotion/src/GoyoShort_20261122.tsx (Root.tsx에 GoyoBH·GoyoOH·GoyoOHShorts 등록)
  - 장면 표(Spec.scenes): instant(0초부터 질문 전부, 페이드 없음), extra(같은 장면에 나중에 붙는 줄), big(도장 한자), art:'sun', note(작은 안내), outro(끝 + 워드마크)
  - fx: glow(아래 오행 색 빛), embers(불씨), sparkles(반짝임, 화면 양옆만). 지금은 화(火) 효과만 있음 → 목(꽃잎 흩날림)·토(흙먼지)·금(반짝 빛)·수(빗방울·물결) 효과를 새로 만들어야 함
  - 위쪽 워드마크 그림(public/goyo_wordmark_20261122.png) + 「오행음악 · 다섯 가지 고요」. 아래쪽 비움(버튼에 가림)
- 완성 예: 11/30 15:00 오화 홍보 릴스 posts/2026-11-30-1500, 쇼츠 4ikUwiRkU_M. 비교판: 맥 remotion/out_20261122/ (병화 무음편 기존 vs Remotion vs 효과판)
- 자세한 실행법: 맥 remotion/README.md, 이 저장소 handoff 이 파일

## 돌리는 법 (클라우드 작업 공간)
1. 맥 remotion 폴더를 가져와 `npm install --ignore-scripts`
2. 정지 화면 `npx remotion still src/index.ts <ID> a.png --frame=N --browser-executable=/usr/bin/google-chrome`
3. 렌더 `npx remotion render src/index.ts <ID> out.mp4 --browser-executable=/usr/bin/google-chrome --concurrency=2` (20초 영상 약 1분)
4. 음악: 기존 릴스 영상에서 소리를 꺼내 쓰면 곡·구간이 그대로(ffmpeg -vn). 새 곡이면 원곡 wav 앞부분 + 곡대응표 등록
