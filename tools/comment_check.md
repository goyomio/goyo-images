# 게시 뒤 댓글 확인 (예약 작업용 지시)

게시가 끝난 다음에 하고, 알림은 게시 결과와 한 번에 보냅니다. 댓글 읽기와 답글은 **직접 API(tools/ig_comments.py)** 로만 합니다. Windsor는 쓰지 않습니다.

C1) 댓글 읽기: cd /home/claude/goyo-images && python3 tools/ig_comments.py list --since "<확인 구간 시작, 예: 2026-11-17T06:00:00+09:00>"
   - 확인 구간은 예약 작업 프롬프트에 적혀 있습니다.
   - goyo_mio 본인 댓글과 이미 goyo_mio가 답글을 단 댓글은 스크립트가 알아서 뺍니다.
   - 오류가 나면 한 번만 다시 시도하고, 그래도 안 되면 알림에 "댓글 확인 실패: 원인"만 덧붙입니다. 게시 결과 알림은 그대로 보냅니다.
   - 토큰(goyo-keys/ig_token.txt)은 절대 출력하거나 다른 곳에 쓰지 않습니다.
C2) 결과가 [] 이면 알림에 댓글 이야기는 넣지 않습니다.
C3) 새 댓글마다 답글 초안을 씁니다.
   - 해요체, 두세 문장. 댓글을 유도하지 않습니다.
   - 효과를 주장하지 않습니다. "채워 준다, 운이 바뀐다, 필요한 사주" 대신 "곁에 두기 좋은 소리"처럼 씁니다.
   - 단정적인 예언, 의료·법률·투자 판단을 하지 않습니다.
   - 링크·URL을 넣지 않고 "프로필 링크 → GOYO"로 안내합니다.
   - 곡은 아래 목록에서만 고릅니다. 각 영상의 첫 곡이며, 지어내지 않습니다.
     - 목: 갑목 Morning Oak(대표), 을목 Morning Tendril
     - 화: 병화 Noon Avenue(대표), 정화 Lamplit Keys
     - 토: 무토 Mountain Desk(대표), 기토 Tilled Morning
     - 금: 경금 Granite Light(대표), 신금 Prism
     - 수: 임수 Wide Water(대표), 계수 Drizzle
   - 영상 이름은 「다섯 가지 고요｜갑목(甲木)」처럼 씁니다.
   - 오행을 두 개 이상 말한 댓글에는 기운마다 대표곡 하나씩, 최대 두 기운까지 소개합니다.
   - "다 있어요/다 없어요"류 댓글은 "사주마다 필요한 기운이 달라서, 고요에는 다섯 오행이 다 있어요"로 받습니다.
   - 악성·광고·스팸 댓글은 초안을 쓰지 않고 "숨기기 추천"으로만 표시합니다. 숨기기는 미오 님이 앱에서 직접 합니다.
C4) 알림에 댓글마다 번호를 매겨 작성자, 원문, 게시물(post), 답글 초안을 붙입니다. 끝에는 "올릴 답글 번호를 말씀해 주시면 게시할게요"라고 씁니다.
C5) 답글은 절대 스스로 게시하지 않고, 숨기기·삭제도 하지 않습니다. 미오 님이 이 대화에서 번호를 지정해 승인한 답글만 아래 명령으로 올립니다.
   python3 tools/ig_comments.py reply <comment_id> "<답글>"
   미오 님이 초안을 고쳐 주셨다면 고친 문장으로 올립니다.

## 추가 규칙 (2026-11-16)
- 곡을 말할 때는 늘 「곡 이름 + 편 이름」으로 적는다. 예: 『Warm Soil』(무토 편). 같은 제목이 여러 편에 있고 노래는 서로 다르다(Warm Soil·Still Meadow: 토1·무토 / Far Shore·Low Tide·Ebb: 수1·임수 / Amber Hour: 토1·정화).
- 답글에도 댓글을 더 요청하는 말(남겨 주세요, 알려 주세요, 댓글로)을 쓰지 않는다.
